# Forest Atelier

A cozy Passpartout-inspired forest art game prototype.

## Run

Open this folder in VS Code and run `index.html` with Live Server (or any local static server).

## Current gameplay

- Customers walk in using the 10-frame character animation in `asset-game/character/`.
- Accept a painting request.
- Draw directly on the in-game canvas.
- Different customers prefer different color moods and levels of visual density.
- The game scores the painting from coverage, color diversity, request color-match and stroke effort.
- Sell or decline the offer.
- Earn coins and reputation.
- Journal tracks progress.
- The finished art appears back on the easel.

## Assets

- Background: `asset-game/background/bg.png`
- Customer animation: `asset-game/character/1.png ... 10.png`
- Painter station: `asset-game/furniture/painting.png`
